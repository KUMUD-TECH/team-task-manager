# 🚀 Team Task Manager

A full-stack web application to manage projects and tasks with **role-based access control**.

Admins can create projects and assign tasks, while members can update task status and track progress through a dashboard.

---

## 🌐 Live Application

👉 **https://team-task-manager-production-becd.up.railway.app/**

---

## ✨ Features

* 🔐 User login (JWT authentication)
* 👥 Role-based access (Admin / Member)
* 📁 Create projects
* ➕ Add members to projects
* 📝 Create and assign tasks
* 🔄 Update task status 
* 📊 Dashboard showing task statistics
* 🗄️ MySQL database integration
* ☁️ Deployed on Railway

---

## 🛠️ Tech Stack

**Frontend:** React
**Backend:** Node.js, Express
**Database:** MySQL
**Authentication:** JWT
**Deployment:** Railway
